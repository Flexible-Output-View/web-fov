Comment ça marche ?

FOV est un logiciel de streaming multi-flux basé sur OBS Studio. Téléchargez-le, installez-le, lancez un stream, et regardez-le en direct sur fovapp.live.

Télécharger FOV

Choisissez votre système d'exploitation. La dernière version est automatiquement récupérée depuis GitHub.

🪟
Windows
.zip — 64-bit
🍎
macOS
.dmg — Apple Silicon
🐧
Linux
.flatpak — x64

Toutes les versions sont disponibles sur GitHub Releases.

En résumé

  1. Téléchargez FOV pour votre OS ci-dessus.
  2. Installez-le en suivant le guide officiel.
  3. Ajoutez vos sources vidéo et audio dans FOV.
  4. Configurez la clé de stream avec le nom de votre choix.
  5. Lancez la diffusion.
  6. Regardez votre live sur fovapp.live.
